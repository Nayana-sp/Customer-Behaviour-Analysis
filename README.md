# Customer Shopping Behavior Analysis

## Overview

An end-to-end data analytics project focused on analyzing customer shopping behavior, purchasing patterns, discounts, subscriptions, and revenue to uncover meaningful business insights.

## Dataset

* **File:** `customer_shopping_behavior.csv`
* **Records:** 3,900 rows
* **Columns:** 18
* **Format:** CSV

## Tools

* **Python:** Pandas, NumPy, Matplotlib, Seaborn
* **MySQL:** Data analysis using SQL queries
* **Power BI:** Interactive dashboard development
* **Jupyter Notebook:** EDA and data cleaning

## Project Workflow

1. **Data Loading:** Imported the dataset using Pandas.
2. **Data Cleaning:** Handled missing review ratings, standardized column names, and created age groups.
3.. **EDA:** Explored data distributions, statistics, and missing values.
5. **SQL Analysis:** Used MySQL to analyze revenue, customer segments, discounts, subscriptions, and product performance.
6. **Dashboard:** Built an interactive Power BI dashboard to visualize key metrics and insights.

## Dashboard

The Power BI dashboard presents customer purchasing patterns, revenue distribution, product performance, and shopping behavior.

## Results

* Analyzed customer purchasing and spending patterns.
* Examined the relationship between subscriptions and spending.
* Identified product-level discount and review trends.
* Segmented customers based on previous purchases.

## Project Files

* `customer_shopping_behavior.csv` — Raw dataset
* `customer_shopping_behavior_analysis.ipynb` — Python analysis and data cleaning
* `sqlfile.sql` — SQL queries
* `Customer_dashbord.pbix` — Power BI dashboard
